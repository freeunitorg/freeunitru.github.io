FreeUnit

Сервер приложений Unit, продолженный сообществом.
Свобода слова в коде.

Оригинальный репозиторий Unit был архивирован в октябре 2025 года.
Мейнтейнеры написали: «Желателен новый мейнтейнер.» FreeUnit — этот мейнтейнер.

Почему FreeUnit

01
🐘 PHP 8.4 + 8.5
Полноценная поддержка современных PHP-рантаймов. Главная причина форка.
02
🔒 Бэкпорты безопасности
Активная поддержка безопасности. Никаких неустранённых CVE в архивированных репозиториях.
03
📦 Стабильные релизы
Предсказуемый цикл LTS-релизов. Продакшен-деплои требуют гарантий.
04
🤝 Управляется сообществом
Без корпоративного контроля. Решения принимают активные контрибьюторы.
05
🌐 WebAssembly
Нативный рантайм wasmtime. WASM-модули работают рядом с PHP, Go и Node.js.
06
🚀 Актуальные рантаймы
Go 1.26, Node.js 24, PHP 8.5. Версии рантаймов отслеживаются и обновляются с каждым релизом.

Установка

# Сборка из исходников
git clone https://github.com/freeunitorg/freeunit
cd freeunit
./configure --openssl --otel
make
sudo make unitd-install
Официальные пакеты скоро появятся.
Docker-образы доступны — смотрите GitHub Packages.
Поддержка PHP 8.5 требует FreeUnit — в архивированном апстриме её нет.

Политика поддержки (EOL)

Рантаймы поддерживаются 1 год после EOL апстрима.
Версии ОС поддерживаются 3 года после EOL апстрима.
Даты отслеживаются на endoflife.date. Версии в пределах 6 месяцев до удаления получают только патчи безопасности.
